Built for Vue 3 applications already using Element Plus 2. Load Element Plus and package CSS, then compose the [documented exports](/en/components/) with typed form fields and explicit table contracts.

The package is independent of host-application APIs. It is a separate UI package from `x-widgets-antdv`; the two frameworks, style systems, and component-specific behavior are not interchangeable.
