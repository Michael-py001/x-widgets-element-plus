# Basic cases

Start with a single `column` schema: one field definition becomes a two-column query form rendered by `SearchForm`, with results shown by the package `Table`. The control gallery puts 18 controls into that same schema, bridged by `FormPage` into one `formData` — edit any field and watch the model update live.
